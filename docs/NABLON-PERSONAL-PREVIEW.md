# Личный предпросмотр Nablon в Telegram

Черновой адаптер `registerPersonalPreview` допускает только один Telegram ID и только в личном чате. Отправитель очереди дополнительно проверяет получателя. Предпросмотр рассчитан на отдельный токен тестового бота и изолированную БД. Он переиспользует маршрут S2 → S3 → S4 и существующий outbox. Рабочая точка запуска его не регистрирует.

## Вход в S2

`/start` получает состояние и стабильный ключ открытия от серверного источника. При отсутствии состояния с подтверждённым предъявлением S2 вход закрыт. Данные из Telegram update и подтверждение отправки Telegram API этого условия не устанавливают.

Для запуска нужен один из двух явно утверждённых вариантов. Можно предоставить достоверный серверный источник предъявления для S2. Другой вариант — разрешить владельцу в личном предпросмотре действовать при неизвестном предъявлении, сохраняя `EXPOSURE_UNKNOWN` и исключая такие действия из доказательств самостоятельности. Правила экспериментального маршрута в обоих случаях остаются отдельным решением. Второй вариант не реализован.

## Черновые подписи

| Команда протокола | Кнопка предпросмотра |
| --- | --- |
| `copy` | Скопировать карточку |
| `settings` | Открыть настройки |
| `check` | Проверить сохранение |
| `delete` | Удалить старый черновик |
| `S4A` | Задача про календарь |
| `S4B` | Задача про старую карточку |

Меняется только отображаемый текст кнопок в личном режиме. Команды, тексты сцен, последствия, лимиты и правила выбора ветки остаются прежними. Выбор S4 открывает сцену. Действия внутри S4 ещё не подключены к Telegram.

## Проверка перед первым проходом

Автоматический тест проверяет отказ чужим аккаунтам и группам, отказ владельцу без подтверждённого S2, идемпотентное открытие после поступления тестового доверенного состояния и работу исходных команд под понятными подписями. Он запускается на одноразовом PostgreSQL с подменой Telegram API через `adaptive/s3-telegram.real.test.mjs`. Условия запуска описаны в `EG-S3-SOURCE-001.md`.

После решения по S2 и утверждения подписей нужен отдельный разрешённый запуск тестового экземпляра. Первый проход закреплён за владельцем и предназначен для проверки понятности интерфейса с телефона. Включение участников и сбор экспериментальной выборки выходят за рамки этого запуска.
