# Личный предпросмотр Nablon — только для владельца

**Решение владельца 2026-11-22:** разрешено допускать корректные действия S2 при `EXPOSURE_UNKNOWN` только в личном предпросмотре. Основные правила Nablon, черновой PR #25, Becoming и Render не изменяются.

## Изоляция и объём

- Используйте **отдельный Telegram-токен** тестового бота и **отдельную PostgreSQL-базу** с именем `nablon_personal_preview` (или `nablon_personal_preview_*`). Не использовать рабочие БД и базу `nablon_orientation_test`. Новый сервис Render не нужен.
- Внешний сервер Telegram сообщает только об отправке. Он не подтверждает чтение сценария или последствия. `EXPOSURE_UNKNOWN` и неподтверждённая самостоятельность сохраняются.
- Внутренний флаг `previewOnly` включается только для специально созданной учебной сессии `NABLON_PERSONAL_PREVIEW`, владельца и изолированного запуска `adaptive/personal-preview.run.js`. Исходный движок по умолчанию продолжает блокировать S2 при `unknown`.
- Предпросмотр **не передаёт** данные в Becoming или Evidence Gate и не входит в экспериментальную выборку.
- Первоначальный S1 — только служебная фикстура для достижения S2. Он не предъявляется владельцу и не является фактом реального прохождения S1. Личное прохождение идёт **от S2 через S3 до выбора и показа S4A/S4B**. Действия внутри S4 пока не подключены.
- Тексты сценариев, последствия, лимиты и команды протокола остаются теми же; изменены только черновые подписи кнопок в личном режиме.

## Язык интерфейса для личного просмотра

**Украинский по умолчанию.** Сценарии, последствия и кнопки выводятся на украинском. Кнопка `🌐 Мова` доступна в сообщениях предпросмотра. При нажатии предлагаются `🇺🇦 Українська` и `🇷🇺 Русский`. Русский появляется **только после явного выбора владельца**. Команда `/language` также открывает выбор языка.

После переключения бот повторно отображает текущее задание и кнопки на выбранном языке. Это повторное отображение, не новый ход, не подтверждение чтения и не новое доказательство самостоятельности. Выбор языка хранится **только в памяти запущенного локального предпросмотра**; после перезапуска снова действует украинский. Для последующего пользовательского пилота потребуется отдельное решение о долговременном хранении выбора языка.

Переводы на украинский пока **черновые**, предназначены для просмотра владельцем. Они не изменяют `adaptive/content.js`, экспериментальные условия и журналы событий. До проведения исследования на людях формулировки переводов должны быть утверждены отдельно. Уже отправленные русские сообщения автоматически не изменяются: после обновления локального экземпляра воспользуйтесь `/language` → `🇺🇦 Українська`, чтобы повторно показать текущую сцену на украинском.

## Отдельный локальный запуск (Codex)

Установите штатные зависимости `npm ci` (или `npm install` при отсутствии актуального lock-файла) и подготовьте отдельный PostgreSQL с именем `nablon_personal_preview`.

Установите переменные среды **локально и приватно**, не в GitHub, не в чате и не в сообщениях об ошибках:

- `PREVIEW_BOT_TOKEN` — токен **отдельного** тестового бота BotFather;
- `PREVIEW_EXPECTED_BOT_USERNAME` — точное имя этого бота без `@`, для защиты от запуска чужого токена;
- `PREVIEW_OWNER_TELEGRAM_ID` — числовой Telegram ID владельца;
- `PREVIEW_DATABASE_URL` — адрес **отдельной** базы `nablon_personal_preview`.

**Не использовать** `DATABASE_URL` рабочего Nablon. Запуск самостоятельно применит `schema.sql` только в выделенной базе. Не запускайте рабочие `index.js` или `bot.js`.

```sh
node --check adaptive/personal-preview.js
node --check adaptive/personal-preview.run.js
node --test adaptive/personal-preview.test.js
node adaptive/regression.js
node adaptive/personal-preview.run.js
```

После успешной проверки токена и начала запуска опроса консоль печатает `Owner-only Nablon preview polling initiated: https://t.me/<test-bot>`. **Это не подтверждение готовности:** Telegram считается доступным для личного просмотра только после фактического получения владельцем ответа на `/start`. Если опрос завершается ошибкой, процесс закрывает соединение с БД, выставляет ненулевой код выхода и сообщает об ошибке без публикации токена.

Отключение — остановить локальный процесс Ctrl+C. Если Telegram ранее использовал вебхук/другой обработчик с этим же токеном, сначала выделите **другой** тестовый токен.

## Сквозная приёмка до первого личного просмотра

С настоящим одноразовым PostgreSQL 17.5 и подменённым Telegram API повторите `adaptive/s3-telegram.real.test.mjs` с `EG_S3_TEST_DATABASE_URL` и `EG_INTAKE_PATH`, а также `adaptive/s3-postgres.real.test.mjs` и тесты без PostgreSQL. Отдельная интеграционная проверка должна доказать: чужой ID и групповой чат отвергаются; S2 c `unknown` разрешён **только** с `previewOnly` и правильной учебной сессией; реальный ход в S2 не меняет `delivery` на `confirmed`; после S3 доступен ручной выбор S4; повтор команды не создаёт второе действие; Telegram `SENT` не доказывает предъявление.

## Контроль исправлений запуска

Тест с намеренно отклонённым вызовом `/start` использует локальный обработчик ошибок Telegraf, который не устанавливает `process.exitCode=1` для ожидаемого исключения. Важно проверять **итоговый** код завершения тестового файла, а не только строки `ok`.

При long polling `bot.launch()` работает до остановки бота, поэтому его Promise не ожидается перед запуском фонового outbox. Ошибки опроса обрабатываются явно. Убедитесь в работе таймера и штатной остановке Ctrl+C.

## Известные ограничения

- Временная локальная среда на компьютере должна быть запущена во время личного прохождения; доступа без работающего процесса нет.
- Telegram может повторно показать сообщение после сбоя между API и фиксацией `SENT`. Журнал действий остаётся идемпотентным.
- Повторный `/start` возобновляет исходную сессию, не создаёт новую; сброс для второго полного прохождения требует явного решения и отдельного безопасного механизма.
- Синтаксическая ошибка `test/nablon-runtime.test.js:65` унаследована от базовой ветки. Не исправлять её в этом ограниченном пакете.
- **Не включать реальных участников, не сливать изменения, не запускать Render, не закрывать четыре P1 и `BLOCKED`.**
